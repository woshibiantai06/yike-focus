「一刻」首个公开测试版 · First public beta of Yike Focus

- **电脑 / Desktop ·** 下载并打开 `Yike-Focus-Desktop.html`。Download and open the HTML file in Chrome or Edge.
- **安卓 / Android ·** 下载 `Yike-Focus-Android.apk`，从文件管理器安装。Download and install the APK from your file manager.
- **功能 / Features ·** 倒计时、正向计时、任务备注、专注报告和中英语言切换。Countdown, count-up, task notes, focus reports, and Simplified Chinese / English.
- **测试范围 / Beta notes ·** 历史记录保存在本机。锁屏和后台声音因设备而异。旧的个人预览版可并存，记录分别存储。History is stored locally. Lock-screen and background sound depend on the device. The old personal preview keeps its own data.
